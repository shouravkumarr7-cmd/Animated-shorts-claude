# Animated Shorts with Claude

This repository is focused on helping users create animated 2D cartoon videos with Claude.

## What this project helps you do

- Plan a short 2D cartoon concept
- Generate a scene-by-scene script with dialogue and actions
- Create visual direction prompts for each shot
- Prepare voiceover and animation-ready production notes

## Suggested workflow

1. Define the cartoon idea (theme, audience, duration, style).
2. Ask Claude to generate:
   - Story outline
   - Scene breakdown
   - Character descriptions
   - Shot list
3. Refine outputs into production assets:
   - Storyboard notes
   - Voiceover script
   - Animation timing cues
4. Export assets into your preferred 2D animation toolchain.

## Example prompt starter

```text
Create a 60-second animated 2D cartoon plan for kids.
Include: title, 6-scene breakdown, character list, dialogue, narration, and shot-by-shot visual prompts.
Style: colorful, playful, simple backgrounds, expressive character animation.
```
